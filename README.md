# Cursor × Zillow Strategic Landing Page

A personalized strategic account landing page for Zillow, inspired by enterprise ABM preview pages.

## View locally

Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Structure

- `index.html` — Landing page content and layout
- `styles.css` — Dark enterprise theme with Cursor branding
