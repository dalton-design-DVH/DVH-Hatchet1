Why Cursor

Unifying Platform Context via Native Composer & .cursorrules

Rather than maintaining expensive, custom-built AI interfaces like "Airbnb-Aware Chat" to supply localized database and API specifications, Airbnb can utilize Cursor's native Composer and directory-specific .cursorrules (.mdc files).

Cursor automatically indexes the entire codebase and applies targeted engineering constraints — Viaduct 1.0 schema patterns, strict TypeScript requirements — directly at the folder level. Multi-step refactoring across Java, Kotlin, Scala, and React in a single turn drove Coinbase to autonomously generate 75% of all code pull requests.
